Create a new ADR for: $ARGUMENTS

1. Find the highest number in `docs/decisions/` and use the next one (4 digits).
2. Copy the structure of `docs/decisions/0000-template.md`. Fill in Context, Decision, Alternatives and Consequences from this conversation and the codebase. Set Status to Accepted and today's date.
3. If it supersedes an older ADR, update that ADR's status line.
4. Link it from any doc it affects (e.g. `docs/architecture.md`, `docs/tech-stack.md`).
